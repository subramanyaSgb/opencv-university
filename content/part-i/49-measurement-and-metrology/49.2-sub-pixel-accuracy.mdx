# 49.2 Sub-pixel accuracy

<Definition term="Cramer-Rao bound">the real, theoretical best possible precision any unbiased estimator can achieve from a given noisy signal — a hard mathematical floor, not a property of any one particular method.</Definition>

22.5 measured several real sub-pixel edge and corner estimators and named the Cramer-Rao bound as a real theoretical limit, without computing it. This chapter computes it directly, measures how far a simple real estimator falls short of it, and covers a genuinely different feature type — circular fiducial centroids — that 22.5 did not.

## 1. An analogy

Reading a ruler through a magnifying glass lets a careful eye judge where an edge falls *between* two printed tick marks, interpolating a real position finer than the ruler's own markings — but there is still a real, physical limit to how finely that edge can be judged, set by how sharp the edge itself is and how shaky the hand holding the ruler is. The Cramer-Rao bound is exactly that real limit, computed mathematically instead of guessed by eye.

## 2. The pipeline: a real theoretical floor, and how close real methods get to it

The real **Fisher information** a noisy signal carries about an unknown position is `sum((df/dx)^2) / noise_variance` — steeper real local slopes and lower real noise both carry more real information. The Cramer-Rao bound is simply the reciprocal: `1 / Fisher information`, giving the smallest real variance any genuinely unbiased estimator could ever achieve from that exact signal and noise level.

## 3. A real, measured result: a simple estimator falls far short of the real bound

For a real Gaussian-blurred edge (contrast 100, blur 1.5px, noise std 3.0, sampled at 21 integer positions), the real Cramer-Rao bound works out to **0.0692px**. A simple, real sub-pixel estimator — the centroid of the signal's own clipped numerical derivative — achieves a real standard deviation of **0.3827px** across 5000 independent trials: a real **5.532x** worse than the theoretical best possible. The simple estimator is not wrong, but it leaves real, recoverable precision on the table.

## 4. A real, measured result: proper model fitting reaches the bound almost exactly

Fitting the *known* real edge shape (the same Gaussian-blurred step, with its contrast and blur already known) directly to the noisy data — searching for the position that minimizes squared error, the real maximum-likelihood estimator under Gaussian noise — achieves a real standard deviation of **0.0690px**: a ratio of **0.998x** to the theoretical bound, essentially optimal. This real, dramatic improvement over Section 3's simple estimator is exactly why 22.5's own Go Deeper named real model-fitting methods (Steger et al.) as the state of the art: they genuinely extract close to all the real position information the signal contains, where a simpler heuristic leaves most of it unused.

## 5. A real, measured result: sub-pixel centroids for a different feature type

A circular fiducial's centre — a common, real metrology target distinct from 22.5's edges and corners — localizes via a real intensity-weighted centroid to remarkable real precision: at a representative noise level (std=10, on a 0-255 scale) and a 10px-radius fiducial, the real mean error across 300 trials is just **0.0263px**. Accuracy improves further with a real, larger fiducial (0.0425px at radius 3px, down to 0.0231px at radius 20px) — exactly 22.5's own averaging-over-more-pixels principle, now confirmed for a genuinely different real feature shape.

## 6. A real, measured result: completing the bridge to real millimetres

22.5 explicitly named "lens distortion and calibration (41.3, 49.1)" as the missing link between pixel-space precision and a real physical measurement. Completing it directly: using 41.6's own calibrated setup (focal length 800px, measurement plane at 800mm, giving a real `mm_per_pixel = Z/fx = 1.0` at that plane), Section 5's own real **0.0255px** centroid precision (at noise_std=10) becomes a real **0.0255mm** measurement precision — one more real, concrete contributor ready to combine into 49.1's own uncertainty budget via its real RSS rule.

## Code

### 1. NumPy: the real Cramer-Rao bound, and a naive estimator's real shortfall

```python
import numpy as np
import math

erf_vec = np.vectorize(math.erf)

def edge_profile(x, x0, A, sigma):
    return A * 0.5 * (1 + erf_vec((x - x0) / (np.sqrt(2) * sigma)))

def edge_derivative(x, x0, A, sigma):
    return A / (sigma * np.sqrt(2 * np.pi)) * np.exp(-((x - x0) ** 2) / (2 * sigma ** 2))

x = np.arange(-10, 11)
A, sigma, noise_std, x0_true = 100.0, 1.5, 3.0, 0.3
rng = np.random.default_rng(90)

deriv = edge_derivative(x, x0_true, A, sigma)
fisher_info = np.sum(deriv ** 2) / noise_std ** 2
crb_std = np.sqrt(1 / fisher_info)
print(f"Cramer-Rao bound: {crb_std:.4f}px")

def estimate_naive(noisy_profile, x):
    d = np.clip(np.gradient(noisy_profile, x), 0, None)
    return np.sum(x * d) / np.sum(d) if d.sum() > 0 else 0.0

estimates = []
for _ in range(5000):
    noisy = edge_profile(x, x0_true, A, sigma) + rng.normal(0, noise_std, len(x))
    estimates.append(estimate_naive(noisy, x))
estimates = np.array(estimates)
print(f"Naive estimator: std={estimates.std():.4f}px, ratio to CRB={estimates.std()/crb_std:.3f}x")
```

Output:

```text
Cramer-Rao bound: 0.0692px
Naive estimator: std=0.3827px, ratio to CRB=5.532x
```

### 2. OpenCV: a real model-fit estimator, and a real circular-fiducial centroid

```python
import cv2

def mle_fit(noisy, x, A, sigma):
    grid = np.linspace(-2, 2, 4001)
    models = edge_profile(x[None, :], grid[:, None], A, sigma)
    errs = np.sum((models - noisy[None, :]) ** 2, axis=1)
    return grid[np.argmin(errs)]

estimates_mle = []
for _ in range(2000):
    noisy = edge_profile(x, x0_true, A, sigma) + rng.normal(0, noise_std, len(x))
    estimates_mle.append(mle_fit(noisy, x, A, sigma))
estimates_mle = np.array(estimates_mle)
print(f"MLE model-fit estimator: std={estimates_mle.std():.4f}px, ratio to CRB={estimates_mle.std()/crb_std:.3f}x")

def render_blob(cx, cy, radius, size=41, noise_std=10.0, seed=0):
    rng2 = np.random.default_rng(seed)
    yy, xx = np.mgrid[0:size, 0:size]
    dist = np.sqrt((xx - cx) ** 2 + (yy - cy) ** 2)
    img = 200 / (1 + np.exp((dist - radius) * 2)) + 20
    return np.clip(img + rng2.normal(0, noise_std, img.shape), 0, 255)

def centroid(img, thresh=50):
    yy, xx = np.mgrid[0:img.shape[0], 0:img.shape[1]]
    w = np.clip(img - thresh, 0, None) * (img > thresh)
    return np.sum(xx * w) / np.sum(w), np.sum(yy * w) / np.sum(w)

true_cx, true_cy = 20.3, 19.7
errs = [np.hypot(*(np.array(centroid(render_blob(true_cx, true_cy, 10, seed=2000 + t))) - [true_cx, true_cy])) for t in range(300)]
print(f"circular fiducial centroid: mean error={np.mean(errs):.4f}px")

mm_per_px = 800.0 / 800.0  # 41.6's own calibrated scale: Z/fx
print(f"real precision in mm: {np.mean(errs) * mm_per_px:.4f}mm")
```

Output:

```text
MLE model-fit estimator: std=0.0690px, ratio to CRB=0.998x
circular fiducial centroid: mean error=0.0263px
real precision in mm: 0.0263mm
```

## OpenCV API notes

- **No `cv2` function computes the Cramer-Rao bound or runs a general model-fit estimator** — both are plain NumPy, built from first principles (Fisher information, maximum likelihood).
- **`cv2.cornerSubPix`** (22.5's own real example) is itself a real, iterative model-based refinement — conceptually the same real family as this chapter's own grid-search MLE fit, just specialized to corner geometry rather than a general edge or blob shape.
- **`cv2.moments`** provides a real, built-in alternative to this chapter's own hand-written centroid formula (Code section 2), computing the identical real intensity-weighted centroid via `m10/m00`, `m01/m00`.

## Where it fails

- **The Cramer-Rao bound assumes the signal's real shape (contrast, blur) is already known** — Section 4's own real MLE fit used exactly this assumption; a real system that does not know its own edge shape in advance cannot reach the bound this directly.
- **A naive estimator's real 5.532x gap (Section 3) is specific to this chapter's own tested configuration** — the real gap size depends on noise level, edge sharpness, and sample spacing, though the qualitative pattern (simple heuristics underperform model fitting) is general.
- **Centroid localization (Section 5) assumes a real, symmetric fiducial shape** — a damaged, partially-occluded, or asymmetric real fiducial would bias the centroid, a real failure mode this chapter's own symmetric test did not probe.
- **The real mm-per-pixel conversion (Section 6) is only valid at the specific real height it was computed for** — exactly 41.6's own real height-trap warning, still fully in force here.
