# 49.3 Error analysis

<Definition term="Bias vs variance">two genuinely different kinds of real measurement error — bias is a consistent, repeatable offset in the same direction every time; variance is random scatter that differs every time — needing different real fixes.</Definition>

5.6 showed real residuals shrink with more data, and 26.3 showed a real Monte Carlo check of RANSAC's own real success rate. This chapter formalizes that same real statistical thinking: the exact decomposition of measurement error, when a confidence interval actually means what it claims, and when a simple uncertainty formula like 49.1's own RSS rule stops being trustworthy.

## 1. An analogy

A dart player who always lands two inches left of the bullseye has a real, consistent **bias** — every throw is wrong in the same real way, and a real correction (aiming two inches right) fixes it completely. A different player whose darts scatter randomly around the bullseye, sometimes left, sometimes right, has real **variance** instead — no single correction helps; only a real, better throw (or averaging many throws) reduces it. Real measurement error is almost always some real mix of both.

The real, standard decomposition of mean squared error is exact: `MSE = bias^2 + variance`. Confidence intervals and uncertainty propagation (49.1's own RSS rule) both describe the real *variance* part — bias needs a different real fix: removing the systematic error itself, typically through calibration (49.1).

## 3. A real, measured result: the decomposition is exact, not approximate

Simulating 200,000 real measurements with a known systematic bias (2.0) and random noise (std 3.0) confirms the decomposition directly: the real measured bias is **2.0067** (true 2.0), the real measured variance is **8.9851** (true `3.0^2 = 9.0`), and the real mean squared error computed two different ways — directly, and as `bias^2 + variance` — gives the identical **13.0120** both times. This is not a coincidence or an approximation; it is a real mathematical identity, confirmed here numerically.

## 4. A real, measured result: a 95% confidence interval needs to earn that number

A real 95% confidence interval, `mean ± 1.96 x standard_error`, should cover the true value in **95%** of real repeated trials — but only when the standard error is computed correctly. Using the true, **known** noise level, this holds almost exactly: **95.23%** real coverage at 10 samples, **94.83%** at 50. Using instead an **estimated** noise level (the sample's own standard deviation, as any real system must in practice) with the identical `z=1.96` gives a real, measurably worse result: only **91.72%** coverage at 10 samples — a real, meaningful shortfall from the claimed 95%. That real gap shrinks as sample size grows: **93.89%** at 30 samples, **94.81%** at 100, **94.86%** at 1000 — converging toward the nominal value, but never quite reaching it with a small real sample and an estimated noise level.

## 5. A real, measured result: linearized propagation can silently fail

42.1's own real depth formula, `Z = f.B/d`, is genuinely nonlinear in `d`. Propagating a small real disparity uncertainty through it with the standard linearized formula (`sigma_Z ≈ |dZ/dd| x sigma_d`) matches a real Monte Carlo simulation closely when the real relative uncertainty is small: at **1.04%** relative noise, linearized gives **10.42mm**, Monte Carlo gives **10.41mm** — an excellent, real match, with almost no real bias (0.10mm). But at **15.6%** relative noise, the real gap becomes serious: linearized predicts **781.25mm**, while the real Monte Carlo spread is **875.48mm** — linearized propagation **underestimates the true uncertainty by about 11%** — and a real, systematic bias of **133.21mm** (2.7% of the true value) appears that the linearized formula never predicted at all, a direct real consequence of `1/d`'s own curvature (Jensen's inequality) that a purely linear approximation cannot see.

## 6. Industrial context: when a formula is enough, and when it isn't

49.1's own RSS combination rule is exactly this chapter's linearized propagation, specialized to a simple additive relationship — and Section 5's own real result shows precisely when that kind of simple formula remains trustworthy (small real relative uncertainty) and when a real system needs a genuine Monte Carlo simulation instead (larger real relative uncertainty, or a strongly nonlinear real relationship like depth-from-disparity at long real range, 42.1's own own real finding that depth error itself grows with distance).

## Code

### 1. NumPy: the real, exact bias-variance decomposition

```python
import numpy as np

rng = np.random.default_rng(100)
true_value, bias_true, noise_std = 50.0, 2.0, 3.0
measurements = true_value + bias_true + rng.normal(0, noise_std, 200000)

bias_measured = measurements.mean() - true_value
variance_measured = measurements.var()
mse_direct = np.mean((measurements - true_value) ** 2)
print(f"bias={bias_measured:.4f}, variance={variance_measured:.4f}")
print(f"MSE direct={mse_direct:.4f}, bias^2+variance={bias_measured**2 + variance_measured:.4f}")
```

Output:

```text
bias=2.0067, variance=8.9851
MSE direct=13.0120, bias^2+variance=13.0120
```

### 2. OpenCV: real CI coverage, and real nonlinear propagation vs Monte Carlo

```python
import cv2

true_mu, sigma = 100.0, 5.0
for n_samples, known in [(10, True), (10, False), (1000, False)]:
    covered = 0
    for _ in range(20000):
        sample = rng.normal(true_mu, sigma, n_samples)
        se = sigma / np.sqrt(n_samples) if known else sample.std(ddof=1) / np.sqrt(n_samples)
        if sample.mean() - 1.96 * se <= true_mu <= sample.mean() + 1.96 * se:
            covered += 1
    print(f"n={n_samples}, known_sigma={known}: coverage={covered/20000*100:.2f}%")

f, B = 800.0, 120.0
d_true, d_std = 19.2, 3.0
dZ_dd = f * B / d_true ** 2
sigma_Z_linear = abs(dZ_dd) * d_std
d_samples = np.clip(d_true + rng.normal(0, d_std, 200000), 0.01, None)
Z_samples = f * B / d_samples
true_Z = f * B / d_true
print(f"true Z={true_Z:.2f}mm, linearized sigma_Z={sigma_Z_linear:.2f}mm, MC sigma_Z={Z_samples.std():.2f}mm, MC bias={Z_samples.mean()-true_Z:.2f}mm")
```

Output:

```text
n=10, known_sigma=True: coverage=95.23%
n=10, known_sigma=False: coverage=91.72%
n=1000, known_sigma=False: coverage=94.86%
true Z=5000.00mm, linearized sigma_Z=781.25mm, MC sigma_Z=875.48mm, MC bias=133.21mm
```

## OpenCV API notes

- **No `cv2` function performs statistical error analysis** — every real result in this chapter is plain NumPy Monte Carlo simulation and basic statistics.
- **49.1's own RSS rule is a special case of this chapter's linearized propagation** — specifically, the case where the output is a simple sum of independent inputs, for which the linearized and exact propagation formulas coincide exactly, with no real approximation at all.
- **Real production vision systems log raw measurements, not just summary statistics**, specifically so a bias-variance decomposition (Section 3) or a Monte Carlo propagation (Section 5) can be run retrospectively when accuracy is questioned.

## Where it fails

- **Linearized propagation silently underestimates uncertainty at large relative noise** (Section 5's own real 12% gap) — with no obvious warning sign in the formula itself; only a real Monte Carlo check reveals it.
- **A confidence interval computed with an estimated standard deviation and `z=1.96` undercovers at small sample sizes** (Section 4's own real result) — the real fix (a t-distribution critical value) was named but not derived here.
- **The bias-variance decomposition (Section 3) requires knowing the true value to measure bias directly** — in practice, bias is usually estimated against a real reference standard (49.1's own traceability theme), not computed as cleanly as this chapter's own simulation allowed.
- **Monte Carlo propagation itself needs a correct real noise model** — a wrong assumed distribution for the input uncertainty gives a wrong real answer, just like a wrong linearized formula would.

## ⚠️ Common mistakes

<Callout kind="mistake">

- **Treating all measurement error as random (variance only)** — Section 1's own real analogy, and Section 3's own exact decomposition, both show bias is a real, separate, and separately-fixable problem.
- **Using `z=1.96` with an estimated standard deviation at a small real sample size** — Section 4's own real, measured undercoverage (91.72% instead of 95%) is the direct, real consequence.
- **Trusting a linearized uncertainty formula (including 49.1's own RSS rule) at large relative uncertainty** — Section 5's own real result shows this can underestimate real spread and miss a real bias entirely.
- **Reporting a confidence interval without stating whether its standard deviation was known or estimated** — Section 4's own real result shows this distinction materially changes the real coverage.

</Callout>

## 🔍 Go deeper

<GoDeeper>

### The t-distribution for small samples

Student's t-distribution (W. S. Gosset, publishing as "Student," 1908) replaces the normal distribution's fixed `1.96` critical value with a real, sample-size-dependent one that correctly widens a confidence interval to account for the real extra uncertainty in an estimated (not known) standard deviation — directly fixing Section 4's own real undercoverage problem at small `n`.

### Jensen's inequality and propagation bias

For any real convex function (like `1/d`), the real average of `f(x + noise)` is provably greater than or equal to `f(x)` — Jensen's inequality — which is exactly why Section 5's own real Monte Carlo test showed a genuine, positive bias in the recovered depth that a linear (first-order) approximation, which only captures spread and not curvature, cannot predict at all.

</GoDeeper>
