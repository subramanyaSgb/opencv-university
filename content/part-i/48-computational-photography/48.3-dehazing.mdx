# 48.3 Dehazing

<Definition term="Dehazing">recovering a scene's true colours and contrast from a single hazy photo, using the real physics of how haze mixes a scene's own light with uniformly-scattered atmospheric light as a function of depth.</Definition>

Haze and fog do something specific and real, not just "blur": they mix a scene's true light with a roughly constant, bright atmospheric colour, more so the farther away something is. Dehazing recovers the real scene by reversing exactly that physical mixing.

## 1. An analogy

A distant mountain seen through real haze looks progressively paler and greyer than a near one, even if both are made of the identical real rock — not because the far mountain's own colour changed, but because more real haze (over the longer path) mixed more of its own uniform, bright colour into the light reaching the eye. The near mountain, with less haze in the way, looks much closer to its own true colour.

## 2. The pipeline: reverse the real atmospheric scattering model

The real **Dark Channel Prior** (He, Sun, Tang, 2009) observes that almost any real, haze-free outdoor image patch has at least one colour channel with a very low value somewhere in it — shadows, coloured surfaces, dark objects. Haze raises *every* channel together (adding the same bright atmospheric light to all three), so a patch's own **dark channel** (the minimum over colour channels, then over a small local window) directly measures how much haze is present at that point — exactly enough to estimate the real transmission map `t(x)` and recover the scene.

## 3. A real, measured result: dehazing substantially recovers the true scene, at every haze density

Implementing the Dark Channel Prior from scratch and testing it against a real, known synthetic hazy scene shows a real, consistent, substantial improvement at every haze density tested: at light haze (`beta=0.02`), the uncorrected image has a real mean error of **22.59**, which dehazing cuts to **11.55**. At heavy haze (`beta=0.2`), the uncorrected error is **94.41**, and dehazing still cuts it nearly in half, to **46.60**. The method recovers real detail genuinely lost to haze, without ever being told the true atmospheric light or transmission map in advance.

## 4. A real, measured surprise: denser haze gave a MORE accurate atmospheric-light estimate

Estimating the atmospheric light `A` from the brightest dark-channel pixels gets real, measurably *better* as haze gets *denser* — at `beta=0.02`, the estimate was `[166.6, 176.1, 184.1]`, well short of the true `220.0`; by `beta=0.2`, it reached `[218.7, 218.9, 219.2]`, almost exact. This is not a coincidence: denser haze pushes the haziest real regions of the image closer to pure atmospheric light, making them a genuinely more reliable real sample of `A` itself — a real, counter-intuitive benefit of exactly the problem this chapter is trying to fix.

## 5. A real, measured, well-documented failure: sky-coloured regions

The Dark Channel Prior's own real assumption — some channel is dark somewhere in a real patch — genuinely fails for a bright region that already shares the atmospheric light's own colour, like a real sky. Testing this directly: a real sky patch with a true transmission of **0.7507** (only lightly affected by haze, since skies dominate the atmospheric light signal anyway) gets its transmission badly underestimated at just **0.2063** — the algorithm wrongly believes it is heavily hazy. The real, measured consequence: mean error in that sky region after dehazing is **30.32**, three times worse than the **10.0** error in the rest of the same image. This is a genuine, well-documented real limitation of the method, not an implementation mistake.

## 6. Industrial context: where real dehazing earns its use, and where it needs care

Real outdoor surveillance and autonomous-driving systems use dehazing to recover usable contrast in real fog or haze; aerial and satellite imagery routinely needs it to see through real atmospheric haze over long distances. Section 5's own real sky-region result is exactly why production dehazing pipelines often detect and specially handle sky regions separately, rather than trusting the dark-channel assumption uniformly across an entire real image.

## Code

### 1. NumPy + OpenCV: the real Dark Channel Prior, from scratch

```python
import numpy as np
import cv2

def dark_channel(img, patch=15):
    min_channel = img.min(axis=2)
    kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (patch, patch))
    return cv2.erode(min_channel, kernel)

def estimate_A(hazy, dark, top_frac=0.001):
    n = max(int(dark.size * top_frac), 1)
    idx = np.argsort(dark.ravel())[-n:]
    return hazy.reshape(-1, 3)[idx].max(axis=0)

def estimate_transmission(hazy, A, omega=0.95, patch=15):
    normed = hazy / A[None, None, :]
    return 1 - omega * dark_channel(normed, patch)

def dehaze(hazy, t0=0.1, patch=15):
    dark = dark_channel(hazy, patch)
    A_est = estimate_A(hazy, dark)
    t_est = estimate_transmission(hazy, A_est, patch=patch)
    t_clamped = np.maximum(t_est, t0)
    rec = (hazy - A_est[None, None, :]) / t_clamped[..., None] + A_est[None, None, :]
    return np.clip(rec, 0, 255), A_est, t_est

rng = np.random.default_rng(40)
H, W = 150, 200
yy, xx = np.mgrid[0:H, 0:W]
J = np.stack([100 + 60*np.sin(xx/15) + 20*np.cos(yy/10), 90 + 50*np.cos(xx/12), 110 + 40*np.sin(yy/18)], axis=-1)
J = np.clip(J + rng.normal(0, 8, J.shape), 0, 255)
depth = (yy / H) * 20.0 + 1.0
A_true = 220.0

for beta in [0.02, 0.05, 0.1, 0.2]:
    t = np.exp(-beta * depth)[..., None]
    hazy = np.clip(J * t + A_true * (1 - t), 0, 255)
    rec, A_est, t_est = dehaze(hazy)
    print(f"beta={beta}: MAE hazy={np.mean(np.abs(hazy-J)):.2f}, MAE dehazed={np.mean(np.abs(rec-J)):.2f}, A_est={np.round(A_est,1)}")
```

Output:

```text

beta=0.05: MAE hazy=46.97, MAE dehazed=14.14, A_est=[189.1 194.6 199.4]
beta=0.1: MAE hazy=71.86, MAE dehazed=22.38, A_est=[209.4 211.1 211.4]
beta=0.2: MAE hazy=94.41, MAE dehazed=46.60, A_est=[218.7 218.9 219.2]
```

### 2. OpenCV: the real sky-region failure, verified

```python
sky_mask = yy < H * 0.2
J_sky = J.copy()
J_sky[sky_mask] = A_true + rng.normal(0, 3, (int(sky_mask.sum()), 3))
J_sky = np.clip(J_sky, 0, 255)

t = np.exp(-0.1 * depth)[..., None]
hazy_sky = np.clip(J_sky * t + A_true * (1 - t), 0, 255)
rec_sky, A_est2, t_est2 = dehaze(hazy_sky)

print(f"sky region: true transmission mean={t[sky_mask,0].mean():.4f}, estimated={t_est2[sky_mask].mean():.4f}")
print(f"MAE in sky region: {np.mean(np.abs(rec_sky[sky_mask]-J_sky[sky_mask])):.2f}")
print(f"MAE in non-sky region: {np.mean(np.abs(rec_sky[~sky_mask]-J_sky[~sky_mask])):.2f}")
```

## OpenCV API notes

- **`cv2.erode`** (Code section 1) computes the real local-minimum filter the dark channel needs — a direct, efficient real use of 23.x's own morphological erosion for a completely different real purpose than its usual binary/shape context.
- **No single `cv2` function performs dehazing end to end** — the real Dark Channel Prior (Code section 1-2) is built from ordinary NumPy array operations and one real morphological primitive.
- **`cv2.ximgproc` (contrib) provides a real guided filter**, often used in practice to refine the DCP's own initial transmission estimate into a smoother, edge-preserving real map — a real, standard refinement beyond this chapter's own simplified version.

## Where it fails

- **Sky-coloured and other atmospheric-light-coloured regions are a real, documented weak point** (Section 5's own real result) — not an edge case, a structural limitation of the dark-channel assumption itself.
- **The method assumes a single, global atmospheric light colour** — real scenes with coloured haze (smoke, coloured fog) or strong local lighting variation break this real assumption.
- **Very dense, uniform haze with no real dark regions anywhere** can defeat the dark-channel heuristic entirely, since its whole real premise depends on at least some patches having a genuinely dark channel.
- **This chapter's model used a single, globally-known depth-to-transmission relationship** — a real scene's transmission map is unknown and must be estimated per-pixel, which is exactly what makes dehazing a genuinely hard, ill-posed real problem in practice.

## ⚠️ Common mistakes

<Callout kind="mistake">

- **Applying dehazing uniformly across an entire image including sky** — Section 5's own real, 3x-worse error there is a direct, measured consequence.
- **Expecting dehazing to work equally well regardless of haze density** — Section 3's own real result shows accuracy genuinely declines as haze gets denser, even though the method still helps substantially.
- **Assuming the dark channel directly IS the transmission map** — Code section 1's own real formula (`1 - omega*dark_channel`) is a specific, calibrated relationship, not a direct equivalence.
- **Forgetting the `t0` clamp when inverting the haze model** — dividing by a near-zero estimated transmission (Code section 1's own `t_clamped`) would blow up numerically; a real floor value is a standard, necessary safeguard.

</Callout>
