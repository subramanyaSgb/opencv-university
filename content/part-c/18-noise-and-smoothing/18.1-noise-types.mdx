# 18.1 Noise types

<Definition term="Image noise">random variation of pixel values that does not come from the scene: the same object photographed twice gives slightly different numbers. Its statistics (how big, whether it depends on brightness, whether it hits few pixels hard or all pixels a little) decide how it can be removed.</Definition>

2.5 explained where sensor noise comes from. This module is about removing it. The first step is to know which kind you have: a filter that is perfect for one kind can be useless or harmful for another. A median filter removes salt-and-pepper noise almost completely, and a Gaussian blur barely touches it; for Gaussian noise the roles are much closer.

## 1. An analogy

Background sounds during a phone call: a steady hiss (Gaussian noise, everywhere a little), louder hiss when the speaker talks loudly (shot and speckle noise, growing with the signal), and occasional loud clicks (salt-and-pepper: rare but extreme). Each needs a different fix.

## 2. Four noise models

    { label: "Signal-dependent: shot (Poisson, variance ∝ v), speckle v · (1 + n)", tone: "process" },

| Noise | Model | Typical source | Looks like |
| --- | --- | --- | --- |
| Gaussian (additive) | v + N(0, σ²) | sensor read noise, amplifier, thermal | fine grain, same everywhere |
| Shot (Poisson) | photon count is Poisson, variance = mean | low light, short exposures (2.5) | grain stronger in bright areas (in absolute terms) |
| Speckle (multiplicative) | v · (1 + N(0, σ²)) | coherent light: lasers, ultrasound, radar | grain proportional to brightness |
| Salt & pepper (impulse) | some pixels → 0 or 255 | dead/hot pixels, transmission errors, dust | isolated black and white dots |

Real numbers on `sample-clean.png`, each noise added at a moderate level (deviation from the clean image):

| Noise | PSNR | Std in dark areas | Std in bright areas | Median absolute error |
| --- | --- | --- | --- | --- |
| Gaussian σ = 20 | 22.2 dB | 19.7 | 18.5 | 13 |
| Shot, 50 photons at white | 20.0 dB | 15.4 | 28.0 | 16 |
| Speckle, σ = 0.2 | 19.2 dB | 10.1 | 35.7 | 16 |
| Salt & pepper, 5 % | 18.1 dB | 34.1 | 36.6 | **0** |

The fingerprints: Gaussian noise is the same in dark and bright areas (the bright value is slightly lower only because values are clipped at 255); shot and speckle noise grow with brightness; salt-and-pepper noise leaves 95 % of the pixels exactly right (median error 0) and ruins the rest completely.

## 3. Measuring noise in your own images

- **Two frames of a static scene**: the difference contains only noise, with standard deviation √2 · σ (14.5). Plot σ against the mean brightness: flat → additive; growing like √(mean) → shot noise; growing linearly → speckle or gain variations.
- **A flat region**: the standard deviation of a uniform patch (after removing any slow gradient).
- **Impulses**: count pixels that differ from the median of their neighbourhood by more than a large threshold.

## 4. Industrial example

A laser-line profiler (Part H) showed noisy profiles on shiny metal. The team first applied a Gaussian blur, which smeared the line and moved its measured centre. Measuring the noise showed speckle: the variation grew with brightness and the pattern changed when the laser moved slightly. Speckle is best reduced at the source: a laser with lower coherence and averaging several frames while the part moves cut it substantially; the remaining noise was handled with a median along the line, which kept the line's position.

## Mini exercise

**Q1.** In a flat dark patch the noise std is 3, in a flat bright patch 12. Which noise type is likely?

<Solution>

Signal-dependent noise: **shot** (std grows like √brightness) or **speckle** (grows linearly). Measure at a third brightness to tell them apart.

</Solution>

**Q2.** Why does PSNR treat 5 % salt-and-pepper noise as worse than Gaussian noise of σ = 20, although 95 % of the pixels are perfect?

<Solution>

PSNR averages squared errors: a few errors of ±200 contribute far more than many errors of ±20. The visual and practical impact also differs: impulses are easy to remove with a median.

</Solution>

## Code

Two examples: simulating the four noise types, then measuring noise against brightness.

### 1. Simulate and measure

```python
import numpy as np
import cv2

clean = cv2.imread("sample-clean.png", cv2.IMREAD_GRAYSCALE).astype(np.float64)
rng = np.random.default_rng(0)
psnr = lambda a, b: 10 * np.log10(255 ** 2 / np.mean((a - b) ** 2))

gaussian = np.clip(np.rint(clean + rng.normal(0, 20, clean.shape)), 0, 255)
sp = clean.copy()
u = rng.random(clean.shape)
sp[u < 0.025] = 0                                                   # pepper
sp[(u >= 0.025) & (u < 0.05)] = 255                                 # salt
speckle = np.clip(np.rint(clean * (1 + rng.normal(0, 0.2, clean.shape))), 0, 255)
shot = np.clip(np.rint(rng.poisson(clean / 255 * 50) * 255 / 50), 0, 255)   # 50 photons at white

for name, x in [("gaussian", gaussian), ("salt&pepper", sp), ("speckle", speckle), ("shot", shot)]:
    d = x - clean
    print(f"{name:12s} PSNR {psnr(x, clean):5.1f} dB | std dark {d[clean < 70].std():5.1f} | std bright {d[clean > 200].std():5.1f} | median |err| {np.median(np.abs(d)):4.1f}")
```

Output:

```text
gaussian     PSNR  22.2 dB | std dark  19.7 | std bright  18.5 | median |err| 13.0
salt&pepper  PSNR  18.1 dB | std dark  34.1 | std bright  36.6 | median |err|  0.0
speckle      PSNR  19.2 dB | std dark  10.1 | std bright  35.7 | median |err| 16.0
shot         PSNR  20.0 dB | std dark  15.4 | std bright  28.0 | median |err| 16.0
```

- Seeding the generator (`default_rng(0)`) makes the experiment repeatable; compare filters on the same noisy image.

### 2. Noise against brightness

```python
import numpy as np
import cv2

levels = [40, 100, 160, 220]
for name, make in [("gaussian", lambda v: v + rng.normal(0, 10, 10000)),
                   ("shot", lambda v: rng.poisson(v / 255 * 200, 10000) * 255 / 200),
                   ("speckle", lambda v: v * (1 + rng.normal(0, 0.1, 10000)))]:
    stds = [make(float(v)).std() for v in levels]
    print(f"{name:8s} std at {levels}: {[round(float(s), 1) for s in stds]}")
```

Output:

```text
gaussian std at [40, 100, 160, 220]: [10.0, 10.0, 9.9, 10.0]
shot     std at [40, 100, 160, 220]: [7.1, 11.3, 14.2, 16.8]
speckle  std at [40, 100, 160, 220]: [4.0, 10.1, 15.8, 21.9]
```

- Constant: additive. Growing like √v (doubling v adds about 41 %): shot noise. Growing in proportion to v: speckle. This plot (a simple form of the EMVA 1288 photon transfer curve, 2.5) identifies the noise in your own camera.

## OpenCV API notes

**Generating noise**: `cv2.randn(dst, mean, stddev)` and `cv2.randu(dst, low, high)` fill an array with Gaussian or uniform random values; NumPy's `default_rng` (normal, poisson, random) is more flexible.

**Measuring**: `cv2.meanStdDev(img, mask=...)` for flat regions; `cv2.PSNR(a, b)` (8-bit images); `cv2.quality` (contrib) for SSIM and others.

**Denoisers by noise type**: Gaussian → `GaussianBlur`, `bilateralFilter`, `fastNlMeansDenoising`; salt & pepper → `medianBlur`; shot noise → transform with an Anscombe transform (Go deeper) or a denoiser with a brightness-dependent strength.

## Where it fails

- **Real noise is mixed**: shot + read noise + fixed-pattern noise + compression artefacts; models are approximations.
- **Structured noise** (stripes, mains hum, banding) is not random per pixel; it needs frequency-domain filters (Part E, 30.4).
- **Clipping** distorts statistics near 0 and 255.

## ⚠️ Common mistakes

<Callout kind="mistake">

- **Assuming all noise is Gaussian** and blurring impulse noise.
- **Measuring noise on textured regions** (texture counts as "noise").
- **Comparing filters on different random noise draws** (seed the generator).
- **Adding noise in uint8** without clipping or with wrap-around (14.3).

</Callout>

## 🔍 Go deeper

<GoDeeper>

### Variance-stabilising transforms

For Poisson data with mean λ, the Anscombe transform 2√(x + 3/8) makes the noise approximately Gaussian with unit variance, independent of λ. Denoise in that domain with a Gaussian-noise method, then invert. This is a standard approach for low-light and fluorescence microscopy images [1].

### Speckle

Speckle arises when coherent light scatters from a rough surface and the scattered waves interfere; fully developed speckle intensity follows an exponential distribution, with a standard deviation equal to the mean (contrast 1). Averaging N independent speckle patterns reduces the contrast by √N [2].

</GoDeeper>

## Exercises

### Exercise 1 (by hand)

A pixel's true value is 100. With speckle noise of relative σ = 0.1, what is the noise std? With shot noise where 255 corresponds to 400 photons?

<Solution>

Speckle: 0.1 · 100 = **10**. Shot: 100 grey levels = 400 · 100/255 ≈ 157 photons, std √157 ≈ 12.5 photons = 12.5 · 255/400 ≈ **8.0** grey levels.

</Solution>

### Exercise 2 (coding)

Estimate the noise σ of the Gaussian-noise image from a flat 30 × 30 patch of the bright square, and with the frame-difference method using two independent noisy copies.

<Solution>

```python
import numpy as np
import cv2

g2 = np.clip(np.rint(clean + rng.normal(0, 20, clean.shape)), 0, 255)
patch = gaussian[40:70, 40:70]                              # inside the bright square (clean value 230)
print(f"flat patch std: {patch.std():.1f}")
print(f"frame difference std / sqrt(2): {(gaussian - g2)[:, :15].std() / np.sqrt(2):.1f}")
```

Output:

```text
flat patch std: 17.6
frame difference std / sqrt(2): 19.9
```

The frame difference (on the left strip, values 60–65, far from clipping) recovers σ = 20; the bright patch underestimates it because values above 255 were clipped. Measure noise away from 0 and 255.

</Solution>
